# Test fixtures

* `D2.csv`, `D3.csv`: functional response data of *Apanteles myeloenta* on
  *Ectomyelois ceratoniae* (second- and third-instar hosts; Kishani Farahani &
  Goldansaz 2013), as compiled in the FoRAGE database (Uiterwaal et al. 2022,
  curves 57 and 58). Columns: `dens` (host density), `par` (hosts parasitized),
  T = 24 h.
* `golden_1.1.0.rds`: reference outputs of funresMech 1.1.0 (engine and
  simulated likelihood), generated by `make_golden.R`. Used by
  `test-regression.R` to check that the default model (Gamma search,
  Lognormal handling) is reproduced exactly by later versions.
